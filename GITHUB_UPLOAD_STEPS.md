# GitHub Upload Steps for DroidForensicX

1. Go to https://github.com
2. Click **New repository**
3. Repository name: `DroidForensicX`
4. Description:

`Free Android defence forensic triage and reporting framework for authorized ADB-based acquisition, app lifecycle analysis, evidence hashing, timeline generation, risk scoring, and professional reports.`

5. Choose Public or Private
6. Do not initialize with README because README already exists
7. Click **Create repository**
8. Click **uploading an existing file**
9. Open the folder `DroidForensicX-GitHub-Upload`
10. Select all files and folders inside it
11. Drag them into GitHub upload page
12. Click **Commit changes**
13. Open README and check the project page

Important:

Do not upload `DroidForensicX-GitHub-Upload.zip` as the only file. GitHub will not automatically extract it.

Extract/open the folder first, then drag the contents inside it.
