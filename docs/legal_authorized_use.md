# Legal and Authorized Use

DroidForensicX was created by Faysal Ferdous.

DroidForensicX is for authorized Android forensic triage only. Use requires consent, ownership, policy authority, warrant, court order, or another lawful basis.

The tool does not implement exploitation, rooting, lockscreen bypass, private database dumping, password decryption, or credential theft. Privacy protection and redaction are defaults.

Do not run DroidForensicX against unrelated devices, accounts, hosts, URLs, APIs, or services.
